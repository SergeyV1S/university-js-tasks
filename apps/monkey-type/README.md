# TypingTest

Тест скорости печати по [макету и заданию в Figma](https://www.figma.com/design/3I4lHawaytZ9DWQlFuxx7k/Typing-Test--Copy-?node-id=661-46).

Из корня репозитория:

```sh
npm install
npm run start:monkey-type:dev
npm run build -w monkey-type
npm test -w monkey-type
```

Адрес разработки: `http://localhost:3003`. Требуется Node.js 22.18+ для запуска тестов TypeScript без отдельного компилятора.

## Поведение

- Слова: 10, 25, 50 или 100; время: 15, 30, 60 или 120 секунд. Настройки режимов независимы.
- «Начать тест» открывает текст. Первый введённый символ запускает таймер и скрывает настройки. Пройденные слова учитываются независимо от ошибок.
- Верные символы светлые, неверные — красные, лишние буквы и пробелы — тёмно-красные. Лишний пробел показан точкой. Слово с ошибкой подчёркнуто; пропущенные буквы становятся красными после перехода к следующему слову.
- Backspace удаляет символ, лишний пробел или возвращает к предыдущему слову. Ошибочные нажатия сохраняются в статистике после исправления.
- В режиме слов тест завершается при вводе последнего символа последнего слова или переходе за последнее слово пробелом. В режиме времени — по таймеру; текст автоматически пополняется. Текущая строка остаётся в видимой области.
- «Заново» сбрасывает ввод и статистику, сохраняя текст и настройки. «Следующий тест» открывает другой текст с теми же настройками.
- Текст берётся из локального набора; шрифт и иконки также локальные. Вставка из буфера и перетаскивание текста отключены.

## Статистика

Считаются все введённые символы, включая пробелы и повторный ввод после исправлений. Backspace и служебные клавиши в статистику не входят.

- **CPM:** верные нажатия × 60 000 / длительность теста в миллисекундах.
- **Точность:** верные нажатия / все введённые символы × 100%.
- **Символы:** все введённые символы.
- **Ошибки:** все неверные нажатия, включая исправленные.

CPM и точность округляются до целого. Таймер использует монотонные часы `performance.now()`, проверяет дедлайн перед каждым вводом и синхронизируется при смене видимости вкладки.

## Структура

- `app` — точка сборки приложения и стили.
- `pages/typing-test` — композиция экрана.
- `features/typing-test` — настройки, ввод, результаты и React-хук таймера.
- `entities/test` — типы, тексты, чистый reducer, правила подсветки и формулы статистики.
- `shared` — общие кнопки, иконки и локальные ресурсы.
- `tests` — проверки логики через встроенный `node:test`.

Размер исходного макета — 1632 × 982. Для узких экранов настройки переносятся на две строки, а результаты — на несколько рядов. Roboto Mono распространяется по SIL Open Font License; лицензия находится рядом с файлом шрифта.
