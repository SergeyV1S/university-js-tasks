# Функциональные требования

Область задания охватывает три экрана приложения, получение рыночных данных от выбранного API, локальный портфель и обмен изменениями между вкладками. Пользователь инициирует поиск, просмотр монеты и ввод покупок. Приложение инициирует фоновые запросы. Внешний API поставляет рыночные данные, браузер предоставляет хранилище и механизм обмена между вкладками. [Строки 8 и 13–22 задания](./task.txt#L8)
