## Отказоустойчивость

Отказоустойчивость применима. Приложение зависит от внешнего API и браузерного хранилища портфеля. При проверке восстановления сети соединение отключают на 5 минут, затем восстанавливают и получают успешный ответ API при снятом ограничении `Retry-After`. Приложение само обновляет данные и снимает отметку об устаревании по ФТ-33–ФТ-34. Восстановление портфеля при временном сбое проверяется по ФТ-54 и НФТ-24. Оба критерия основаны на результате восстановления. Согласование В-НФТ-01. [Строки 18–19 и 22](./task.txt#L18)
