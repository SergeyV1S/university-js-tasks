# Бизнес-требования

Продукт представляет собой учебное браузерное приложение для обзора рынка криптовалют, изучения отдельных монет и оценки собственного портфеля. Пользователь работает с рыночными данными и вводит сведения о покупках. Проверяющий оценивает выполнение задания. [Источник задания](./task.txt#L1)

## Цели и критерии достижения

| ID    | Ожидаемый результат                                                                                                                                                               | Критерий достижения                                                                                                                                                                                                             | Статус и источник                                                                                                                                                                |
| ----- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| БТ-01 | Продемонстрировать навыки проектирования SPA, интеграции с внешним API, работы с глобальным состоянием, оптимизации сетевых запросов и обеспечения отказоустойчивости интерфейса. | При учебной приёмке проверяющий подтверждает все пять навыков по связанным ФТ и НФТ, наблюдая работу приложения или проверяя код.                                                                                               | Подтверждено источником. Критерий согласован по В-БТ-01. [Строки 1, 5–10, 13 и 19–24](./task.txt#L1)                                                                             |
| БТ-02 | Дать пользователю возможность оценивать состояние рынка и отбирать монеты по своим условиям.                                                                                      | На контрольном наборе рыночных данных участник получает сведения о состоянии рынка по доступным метрикам и находит нужную монету или список монет в заданном ценовом диапазоне.                                                 | Выведено из источника. Сводка рынка, таблица, поиск и фильтрация поддерживают этот результат. Критерий согласован по В-БТ-01. [Строки 14–16](./task.txt#L14)                     |
| БТ-03 | Дать пользователю возможность оценивать изменение цены выбранной монеты и сопоставлять её стоимость в USD, EUR и BTC.                                                             | На примере монеты с известной историей и курсами участник определяет изменение цены за выбранный период и получает результат пересчёта в каждой из трёх валют.                                                                  | Выведено из источника. График и конвертер поддерживают оценку одной монеты. Критерий согласован по В-БТ-01. [Строка 17](./task.txt#L17)                                          |
| БТ-04 | Дать пользователю возможность оценивать стоимость, результат и структуру своих вложений на основе зарегистрированных покупок и рыночных котировок.                                | На контрольном портфеле с известными покупками и котировками участник определяет общую стоимость, прибыль или убыток и долю каждой монеты. После повторного открытия приложения сохранённые покупки доступны для той же оценки. | Выведено из источника. Учёт покупок, сводный расчёт, диаграмма и сохранение портфеля поддерживают этот результат. Критерий согласован по В-БТ-01. [Строки 18–19](./task.txt#L18) |

Учебная приёмка завершена, когда проверяющий подтвердил пять навыков и участник успешно выполнил все три сценария БТ-02–БТ-04.
